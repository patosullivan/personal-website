# Patrick O’Sullivan’s homepage

Static HTML and CSS with a self-hosted variable font.

## Local preview

Run `python3 -m http.server 8000 --directory public` and open http://localhost:8000.

## Deployment

Netlify serves `public/` using the configuration in `netlify.toml`. No build or dependency installation is required.
